# ARTIFACT.md — reproducibility package

What this repository's evidence campaign was run on, what is committed, and how long each
reproduction path takes. See `paper/sections/C_reproduction.tex` for the manuscript-facing version of
this guide and `docs/CAMPAIGN.md` for the full campaign runbook.

## What is committed

- **Code, policies, Makefile, manuscript source** — the whole repository.
- **`paper/data/`** — the exact per-run data behind every number in `paper/`: `raw.csv` +
  `manifest.jsonl` for each of the three campaign arms (`paper-live`, `paper-baselines`,
  `paper-mock`), the graded adversarial corpus (`adversarial.json`), and the two adversarial runs
  from before the L6 contract fixes (`adversarial_before_fix_*.json`, the evidence for that finding).
  ~1.1 MB total. `paper/data/SHA256SUMS` checksums every file in this directory.
- **`paper/generated/`** — every table, figure and the `numbers.tex` macro file the manuscript quotes,
  plus its own `SHA256SUMS`. Regenerating from `paper/data/` reproduces these files byte-for-byte
  (verified: `paper_artifacts --root paper/data` vs.\ `--root results` after the live campaign produce
  identical output hashes).
- **Not committed**: the full `results/` working directory (git-ignored; regenerated by re-running the
  experiments), and the LLM provider keys used for the live arm (never written to any manifest,
  result, or committed file — provenance records model identifiers only, `paper/data/*/manifest.jsonl`).

## Environment the live campaign ran on

- **Hardware**: one Apple Silicon (`arm64`) Mac, macOS 15.7.2 (build 24G325). Runs are strictly
  sequential (the resource-contention scenario is real host CPU stress, so host load is part of the
  measurement — parallel runs would contaminate it).
- **Container runtime**: Docker 29.6.1.
- **Python**: 3.11.7 (`requires-python = ">=3.11,<3.12"`), dependency-locked via `uv 0.12.15`
  (`uv.lock` committed).
- **Stack image pins**: `postgres:16.6`, `openpolicyagent/opa:0.68.0-debug` (load-bearing —
  `paper/sections/06_lessons.tex`, L6), `redpandadata/redpanda:v24.2.18`,
  `apache/airflow:2.10.5-python3.11`.
- **Live model provider**: OpenAI-compatible endpoint (`llm_provider=openai_compatible`); reasoning
  agents used `nvidia/nemotron-3-ultra-550b-a55b`, the monitoring agent used
  `nvidia/nemotron-3-super-120b-a12b` (recorded per run in every `manifest.jsonl` line, never
  hand-typed here).
- **PDF toolchain**: Tectonic 0.17.0 (self-contained; fetches its own TeX bundle on first run, no
  system LaTeX install needed).
- **Campaign dates**: launched 2026-09-22, completed 2026-09-26 (git history and `paper/data/*/manifest.jsonl`
  timestamps are authoritative).
- **Code revision**: two `git_sha` values appear across `paper/data/*/manifest.jsonl` because the
  campaign's supervisor was restarted mid-run after a host infrastructure failure unrelated to the
  experiment, picking up a same-day fix to the supervisor's own health check. Verified by diff to
  touch nothing on a run's execution path; see `DEVIATIONS.md` D-104m/D-104n.

## Expected runtimes

| Path | Command | Time | Cost |
|---|---|---|---|
| Regenerate every table/figure/number and the PDF from committed data | `make paper-repro-quick` | < 15 min | none |
| Full unit-test suite (no Docker, no network) | `make test-unit` | ~35 s | none |
| Mock quick matrix (96 runs, sanity check only) | `make experiment-quick` | 15–90 min | none |
| Re-run the full live paper campaign from scratch | `docs/CAMPAIGN.md` | ~2 days | real API spend (this run: 975,570 tokens against a 1,300,000 ceiling) |

## ACM artifact-badge self-assessment

Not submitted for official badging (no venue chosen yet — see `paper/main.tex`), but self-assessed
against the ACM criteria (<https://www.acm.org/publications/policies/artifact-review-and-badging-current>)
as a maturity statement:

| Badge | Self-assessment | Why |
|---|---|---|
| **Available** | Met | Code, policies, committed per-run data (`paper/data/`) and the manuscript are all in one public repository; an archived release with a persistent identifier is minted at submission (Zenodo DOI, `.zenodo.json`). |
| **Functional** | Met | Documented (`ARTIFACT.md`, `docs/CAMPAIGN.md`, `README.md`), exercisable end-to-end (`make paper-repro-quick` regenerates every table/figure/number from committed data in <15 min; `make test-unit` runs 752 tests with no Docker/network), and consistent with the paper's claims (Appendix~`A_claims_audit`, `paper/sections/A_claims_audit.tex`, traces every quoted number to its generating script). |
| **Reusable** | Partial | The analysis pipeline (`src/acde/analysis/`), adversarial-corpus generator, and campaign supervisor are general enough to run against a different `results/` layout or a re-run campaign without modification, and are unit-tested to the repository's ≥80% coverage bar. What is *not* yet reusable beyond this project: the four fault scenarios and accepted-mitigation taxonomy are specific to this testbed (`src/acde/experiments/scenarios.py`, `decision_quality.py`), and no packaging (e.g. a pip-installable standalone artifact) exists for the analysis pipeline in isolation. |
